Email(Apex + VisualForce)

Step 1: Verify Email Deliverability (Crucial!)
Go to Setup (Gear Icon).
Type Deliverability in the Quick Find box.
Ensure Access level is set to All email. Save.

Step 2: Create the Apex Controller
Open the Developer Console.
Go to File -> New -> Apex Class.
Name it EmailServiceController.
Paste the Apex code and save (Ctrl+S).

public class EmailServiceController {
    public Blob fileBody {get;set;}
    public String fileName {get;set;}
    public String toEmail {get;set;}

    public void sendEmail(){
        if(toEmail == null || !toEmail.contains('@')){
            ApexPages.addMessage(
                new ApexPages.Message(
                    ApexPages.Severity.ERROR,
                    'Invalid Email Address'
                )
            );
            return;
        }

        Messaging.SingleEmailMessage mail =
            new Messaging.SingleEmailMessage();

        mail.setToAddresses(new String[] {toEmail});

        mail.setSubject('Salesforce Email Service');

        mail.setPlainTextBody(
            'Hello, this is a test email with attachment.'
        );

        Messaging.EmailFileAttachment attachment =
            new Messaging.EmailFileAttachment();

        attachment.setFileName(fileName);

        attachment.setBody(fileBody);

        mail.setFileAttachments(
            new Messaging.EmailFileAttachment[] {attachment}
        );

        Messaging.sendEmail(
            new Messaging.SingleEmailMessage[] {mail}
        );

        ApexPages.addMessage(
            new ApexPages.Message(
                ApexPages.Severity.CONFIRM,
                'Email Sent Successfully'
            )
        );
    }
}


Step 3: Create the Visualforce Page
In the Developer Console, go to File -> New -> Visualforce Page.
Name it EmailServicePage.
Paste the Visualforce XML code and save.

<apex:page controller="EmailServiceController">
    <apex:form enctype="multipart/form-data">       
        <apex:pageMessages/>
        <apex:pageBlock title="Send an Email">            
            <apex:pageBlockSection columns="1">                 
                <!-- inputText supports the label attribute natively -->
                <apex:inputText value="{!toEmail}" label="Recipient Email"/>               
                <!-- inputFile requires a pageBlockSectionItem wrapper to have a label -->
                <apex:pageBlockSectionItem>
                    <apex:outputLabel value="Attachment"/>
                    <apex:inputFile value="{!fileBody}" filename="{!fileName}"/>
                </apex:pageBlockSectionItem>               
            </apex:pageBlockSection>
            
            <apex:pageBlockButtons location="bottom">
                <apex:commandButton value="Send Email" action="{!sendEmail}"/>
            </apex:pageBlockButtons>            
        </apex:pageBlock>
    </apex:form>
</apex:page>

Step 4: Test the Application
Click the Preview button on the Visualforce page.
Test the Validation: Leave the email field blank or type "invalidEmail" (without an @ symbol) and click "Send Email". You should see a red error message appear.
Test the Success: Enter your actual email address, upload a small text file or image, and click "Send Email". You should see a green confirmation message and receive the email with the attachment shortly after.
